Get update notifications (Obtainium / ObtainX)

  1. Install Obtainium or its fork ObtainX on the phone.
  2. Open this page on the phone, pick a tab, and tap Add to Obtainium / ObtainX on an app. Confirm the import.
  3. In Obtainium, open the app and tap Install.
  4. Done: Obtainium checks for new builds in the background and notifies you. Tap the update to install it.
  5. Button does nothing (no Obtainium yet, or a desktop browser)? Open the app's Manual setup and copy the values from there.

Already have the official app? (Curbox, inkOS, Grayscaler)

The build here uses the same app id but a different signing key, so Android won't install it over the official one, and Obtainium can hold only one entry per app id.

Switch to the build here and drop the official one

  1. Back up the app's data from its own settings.
  2. In Obtainium, open the official app's entry and Remove it.
  3. Uninstall the official app.
  4. Add and install the build here (steps 2–3 above).
  5. Restore the backup.

Keep hearing about official releases too

  1. Curbox and inkOS here are rebuilt from every official release within about a day, so their entries already follow official versions.
  2. For a separate heads-up, remove the official Obtainium entry (as a normal entry it would try to install the official APK over this build and fail).
  3. Add the official repo again (link in the app's card) with Track-only on. It only notifies, never installs.
  4. Or, without Obtainium: on GitHub, open the official repo → Watch → Custom → Releases.
Builds are published by each app's GitHub Actions on every push to its main branch, or from the PC with scripts/publish-local.ps1.
